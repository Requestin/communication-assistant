## Цель простыми словами

На сайте можно «войти» четырьмя карточками без пароля. Менеджер видит пустой инбокс, главный — пустую админку. Чужие пункты меню не показываются.

**Готово когда:** можно войти четырьмя людьми и не увидеть чужой пункт меню.

## Чеклист работ

- [ ] `/login` — четыре карточки: Анна Соколова, Дмитрий Орлов, Елена Волкова, Игорь Белов (имена и email из §2.1).
- [ ] `POST /api/auth/login` `{ userId }`, httpOnly cookie `ca_session` (JWT или iron-session), секрет из `SESSION_SECRET`, срок 7 дней.
- [ ] `GET /api/auth/me`, `POST /api/auth/logout`.
- [ ] Middleware: нет cookie → `/login`; `manager` на `/admin` → редирект на `/inbox`; `chief` может открыть `/inbox` и `/admin`.
- [ ] `/inbox` — слева пустой список клиентов, справа пустая лента, внизу поле ответа и кнопки можно показать disabled с подсказкой «писем ещё нет».
- [ ] `/admin` — каркас с нулями (карточки отдела, пустая таблица менеджеров). Графики-заглушки допустимы.
- [ ] Шапка: имя, роль, «Выйти». У менеджера нет ссылки «Админка». У главного — есть.
- [ ] Debug API рейсов: закрыть от анонимов; лучше пускать только `chief` (как задумано в этапе 1).
- [ ] Автотесты API: логин, me, logout, 403/редирект менеджера на админку, chief проходит.

Почту, ИИ и поллинг ленты на этом этапе не подключать.

```bash

npm test
```

Покрыть хотя бы:

- логин существующим userId ставит cookie;
- несуществующий userId → 400/404;
- менеджер не получает данные `/api/admin/stats` (если маршрут уже есть как заглушка 403);
- chief — `role=chief`.

## Ручная проверка (нужна)

Агент **не закрывает этап**, пока человек не прошёл экран или явно не написал «UI ок». Отправьте человеку этот текст:

### Инструкция для проверки экрана

1. Откройте `http://127.0.0.1:3010` (если не открывается — напишите агенту; возможно, web не запущен или слушает другой адрес).
2. Должен открыться вход с **четырьмя** карточками, без полей пароля.
3. Войдите как **Анна Соколова**.
   - Видны пустой список клиентов и пустая переписка.
   - В меню **нет** «Админка».
   - Есть «Выйти».
4. Выйдите. Войдите как **Игорь Белов**.
   - Есть админка с нулями.
   - Можно открыть инбокс (пустой).
5. Снова войдите как Анна и в адресной строке откройте `/admin`.
   - Вас должно увести на инбокс, админку не показать.
6. Напишите агенту: что увидели и ок ли вёрстка (криво / нормально для пилота). Приложите скрин, если что-то не так.
