## Цель простыми словами

Кнопка «Подобрать решение» читает переписку, ищет в таблицах рейсы и отели и кладёт в ленту служебную карточку с 1–2 пакетами. Клиенту это письмо не уходит.

**Готово когда:** заявка «двое, Москва–Петербург, 01.09–05.09» даёт пакет с рейсами и отелем; «в Томск» — вежливый отказ. Сумма пересчитана кодом.

## Чеклист работ

- [ ] `POST /api/conversations/:id/suggest` ставит `Job suggest_travel`. Повторные нажатия — новая карточка.
- [ ] Шаг 1: LLM → JSON разбора заявки (§9.2).
- [ ] Резолвер городов по `City.aliases` **кодом** после модели («Питер» → `LED`).
- [ ] Шаг 2: SQL только по городам и датам, лимиты 8+8+8. Модель SQL не пишет.
- [ ] Ночи отеля: с `dateFrom` по `dateTo-1`. Двое людей — `twin` или два `standard`, что реально есть и дешевле.
- [ ] Шаг 3: LLM выбирает 1–2 пакета **только из переданных id**.
- [ ] Код сверяет id со списком и **сам** считает `totalRub`.
- [ ] `AiNote` типа `travel_offer`, текст «учебные данные, не оферта».
- [ ] Кнопка «вставить в ответ» желательна, не блокер.
- [ ] Спиннер «ИИ подбирает варианты…» пока job `processing`.
- [ ] Автотесты без обязательной живой модели:
  - резолвер: Питер/СПб/LED, МСК, Владик, неизвестный Томск;
  - расчёт ночей 01.09–05.09 → 4 ночи;
  - сумма пакета = рейсы×люди + отель за ночи;
  - подмена id моделью отвергается;
  - SQL-выборка на инвариант §12.6 возвращает кандидатов (интеграция с БД).

Не внедрять RAG и tool-calling.

## Ручная проверка (нужна)

### Инструкция для человека

1. Войдите как Анна, откройте ленту, где есть заявка на Петербург 1–5 сентября (или пришлите такое письмо ещё раз и ответьте с сайта коротко, что заявку приняли).
2. Нажмите **Подобрать решение**. Дождитесь карточки (до двух минут).
3. В карточке должны быть рейс туда, рейс обратно, отель, сумма в ₽ и пометка, что данные учебные.
4. Напишите в ту же или новую ленту входящее «нужна командировка в Томск на неделю» (или вставьте такое в переписку, если агент даст тестовый способ). Снова подбор — должен быть вежливый отказ: города нет в справочнике.
5. По желанию: Казань или Владивосток в ноябре/декабре 2026 — пакет или честное «нет мест».
6. Напишите агенту: нашёлся ли Петербург, отказал ли Томск, сошлась ли сумма «на глаз».
