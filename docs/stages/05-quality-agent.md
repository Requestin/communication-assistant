## Цель простыми словами

После отправки ответа ИИ сам ставит оценки. Если ответ небрежный — в ленте жёлтая карточка, которую клиент не получает.

**Готово когда:** нарочно плохое письмо («ок ща сделаю камандировку!!!») даёт подсказку; аккуратное деловое — молчит или почти молчит.

## Чеклист работ

- [ ] Сервис `llm` в compose: `llama-server`, порт **8088**, GPU, модель по `LLM_GGUF_PATH` (§6.2). Если GPU-контейнер не встаёт — запасной запуск на хосте, как в архитектуре; написать человеку.
- [ ] `src/lib/ai/llm.ts`: `completeJson`, retry при кривом JSON, таймаут 120 с.
- [ ] Промпт в `prompts/quality-system.md` по черновику §9.1.
- [ ] После SMTP создавать `Job evaluate_quality`.
- [ ] Воркер обрабатывает job: вызывает модель, пишет `QualityScore`, при `showHint=true` создаёт `AiNote` типа `quality_hint`.
- [ ] UI: янтарная карточка, бейдж «Только для сотрудников», баллы и `hint`.
- [ ] Входящие клиента не оценивать.
- [ ] Автотесты: парсинг валидного JSON; невалидный JSON → retry/fail без падения API; `showHint=false` → нет AiNote, score есть; мок LLM, без обязательного живого GPU в unit-тестах.
- [ ] По возможности один интеграционный вызов живой модели. Если модель не поднялась — не блокировать merge unit-тестами, но **попросить человека** прогнать два ответа.

## Ручная проверка (нужна, живая модель)

### Инструкция для человека

1. Дождитесь, пока агент напишет, что `llm` слушает `8088` (первый старт модели долгий).
2. Войдите как Анна, откройте ленту клиента.
3. Отправьте **плохой** ответ: `ок ща гляну камандировку!!!`
4. Подождите до двух минут. Должна появиться жёлтая карточка с замечаниями. В почте клиента этой карточки нет — только текст письма.
5. Отправьте **нормальный** ответ: `Добрый день! Получили заявку на командировку двух сотрудников по маршруту Москва — Санкт-Петербург с 1 по 5 сентября 2026 года. Подберём варианты и вернёмся с предложением. С уважением, Анна Соколова`
6. Карточки быть не должно или она очень мягкая.
7. Напишите агенту: была ли карточка на шаге 4 и 6, и сколько ждали.

## Что попросить человека

- Если контейнер `llm` не стартует: разрешение запустить `llama-server` на хосте или лог ошибки **без** секретов.
- Не поднимать одновременно лишние тяжёлые GPU-сервисы (Ollama + ComfyUI), см. §16.
- Пройти два ответа выше.

## Откат

- До merge: сброс ветки; остановить `llm`, чтобы освободить GPU.
- После merge: revert-PR.
- Неудачные jobs оставить `failed` — не чистить вручную без нужды.

## Definition of done

- Юнит-тесты JSON/job зелёные.
- Человек подтвердил жёлтую карточку на плохом письме (или зафиксирован блокер модели).
- Письмо клиенту без служебного текста ИИ.
- PR влит в `main`.
