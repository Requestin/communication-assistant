## Как агент ведёт этап

1. Прочитать этот файл этапа и указанные разделы `ARCHITECTURE.md`.
2. От актуального `main` создать ветку из таблицы.
3. Сделать только этот этап, не забегать вперёд.
4. Написать и прогнать автопроверки из файла этапа.
5. Если нужен взгляд на UI или живая почта — остановиться и дать человеку пошаговую инструкцию из файла этапа.
6. После зелёных проверок: коммит → PR `[stage NN] …` → merge в `main` (агент делает сам).
7. Если сломалось — чинить самому или откатить по разделу «Откат» файла этапа. `git push --force` в `main` запрещён.
