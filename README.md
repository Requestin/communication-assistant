# Помощник в коммуникации с клиентами

Пилот для менеджеров командировок: живая почта Gmail, оценка ответов и подбор учебного пакета «авиа + отель» локальной моделью. Это демонстрация, не коммерческий продукт. В интернет сервис ходит только в Gmail.

Сайт: [https://assistant.gyhyry.com](https://assistant.gyhyry.com) (с сервера также [http://127.0.0.1:3010](http://127.0.0.1:3010)). Порты **3000 / 5432** на этом сервере заняты **mapvideo** — их не занимать и не останавливать.

## Запуск

Из каталога репозитория. Nginx и mapvideo не трогать.

```bash
./scripts/up.sh          # модель в tmux + Docker: db, сайт, воркер
./scripts/down.sh        # выключить это же; письма в томе БД остаются

# после смены кода сайта/воркера:
./scripts/up.sh --build

tmux attach -t commassist-llm   # логи модели; отцепиться: Ctrl-b, затем d
```

Или `npm run up` / `npm run down` / `npm run llm:attach`.

Не коммитьте `.env`. Не `docker compose down` вне этого каталога и не `docker stop` контейнеров mapvideo.

## Сценарий показа (5–7 минут)

1. Откройте `http://127.0.0.1:3010`, войдите как **Анна Соколова**. Пароля нет.
2. С другой почты напишите на `communicationassistant36@gmail.com`: двое, Москва–Петербург, 1–5 сентября.
3. Письмо появится в ленте. Ответьте с сайта нарочно плохо: «ок ща гляну камандировку!!!» — жёлтая подсказка только для сотрудников.
4. Ответьте нормальным письмом. Нажмите **Подобрать решение** — пакет с рейсами, отелем и учебной суммой.
5. **Вставить в ответ**, отправить. Клиент получает только текст менеджера, не карточку ИИ.
6. Выйдите, войдите как **Игорь Белов**. Консоль: цифры по отделу, провал в ленту Анны.
7. По желанию: заявка «в Томск» — вежливый отказ, города нет в справочнике.

Рейсы и отели учебные, цены не настоящие. Модель на своей видеокарте, в облако текст не уходит — кроме самого Gmail.

После пилота смените пароли приложений Gmail: они звучали в рабочих чатах.
