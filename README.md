# Помощник в коммуникации с клиентами

Пилот веб-сервиса для менеджеров командировок: переписка с клиентами, фоновая оценка ответов локальной моделью и подбор учебных пакетов «авиа + отель».

Это демонстрация возможности, не коммерческий продукт. Сайт, база и ИИ — на своём сервере. В интернет сервис ходит только в Gmail.

## Запуск

Каркаса приложения в репозитории ещё нет (этап 0 впереди). Когда появится:

```bash
cp .env.example .env
# заполнить SESSION_SECRET, POSTGRES_PASSWORD и пароли приложений Gmail локально

docker compose up --build -d
```

Сайт: `http://127.0.0.1:3010` (порт 3000 на сервере уже занят).

Модель: `docker compose up -d llm` слушает `127.0.0.1:8088`. На этом сервере контейнер с хостовым `llama-server` не стартовал (нет `libgomp` в CUDA runtime-образе) — запасной путь из архитектуры: `llama-server` на хосте, bind `127.0.0.1:8088`, в `.env` для хостового воркера `LLM_BASE_URL=http://127.0.0.1:8088/v1`. Не поднимайте Ollama/ComfyUI рядом без нужды. Не запускайте одновременно `commassist-worker` и `npm run worker`.

Не коммитьте `.env` и не публикуйте пароли почты.
